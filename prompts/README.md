# Prompts

Six prompts I use, written so the AI works with you step by step. Each one:

1. asks you a few questions **one at a time**, with an example and a default you can accept,
2. checks anything unclear or contradictory before going on, never guessing,
3. plays back its plan and waits for your "go",
4. then produces a structured result, with sources where facts are involved.

Paste the text inside the box into ChatGPT, Gemini or Claude and answer its questions.

Every prompt follows Anthropic's **4D AI Fluency framework**: the prompt itself is the *Description*, and each file ends with a short *Before you use the result* section covering *Delegation* (what the AI does and what stays with you), *Discernment* (what to check) and *Diligence* (data and being open about AI use).

| Prompt | What you get |
|---|---|
| [Two-company teardown research](company-teardown-research.md) | A sourced fact base with confidence tags for comparing two companies |
| [Role requirements and question bank](role-question-bank.md) | What employers test for each role, plus 12 scenario questions per role |
| [Simulated interviews](simulated-interviews.md) | AI role-played users to sharpen hypotheses (clearly labelled, never evidence) |
| [Launch strategy market research](launch-market-research.md) | Demand, pricing, competitors and willingness to pay, every number sourced |
| [Coin image grid PDF](coin-image-grid-pdf.md) | Numista images laid out as printable binder pages (Claude Code) |
| [Matching portfolio tiles](portfolio-tile-illustrations.md) | A set of square illustrations in one shared style |
